# Ishan Gokhale portfolio

Personal design and woodworking portfolio. Static HTML, CSS, JavaScript and locally hosted images and fonts.

## Cloudflare Pages

- Production branch: main
- Framework preset: None
- Build command: python3 build.py
- Build output directory: dist
- Root directory: leave blank

## Editing

Edit content.json for project titles, wood species and captions. Edit intro.json for the biography. Run python3 build.py to regenerate HTML. Layout and animation live in dist/style.css and dist/intro.js. Keep original photo proportions and the approved captions.

All 30 photographs and fonts are included. No API keys, database or paid runtime are required. Cloudflare publishes updates from the production branch automatically once connected.
